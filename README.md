# West Bench development

A screening page of active zoning and planning cases in the West Bench neighborhood association area of Boise, Idaho, built from the City of Boise's public case records: each case's stage and timeline, flags for anything neighbors may want to weigh in on, the drawings filed with the city, and a lot map.

**Live page:** https://hydrotylerking.github.io/west-bench-development/

This is a one-time snapshot from Nov 6, 2026. It is not an official city record and is not affiliated with the City of Boise. To discuss automatic daily updates, contact hydroty@gmail.com.

## Publishing

GitHub Pages serves `index.html` from the `main` branch (Settings → Pages → Deploy from a branch → `main`, `/ (root)`).
